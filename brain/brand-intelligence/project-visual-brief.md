## H. Anti-monotony comparison

- repeated background family?
- same dark-sidebar/light-canvas pattern?
- same accent family?
- same serif/sans pairing?
- same card radius/elevation?
- same density and spacing rhythm?
- same illustration/photo treatment?

If several answers are yes, explain why the repetition is product-driven or generate a materially different direction.
