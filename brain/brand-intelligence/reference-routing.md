# Reference Routing Matrix

Use this file to choose the right research source before designing. Do not browse inspiration randomly.

| Design question | Start here | Then validate with | Avoid treating as proof |
| --- | --- | --- | --- |
| What do shipped products in this category actually do? | Mobbin, Refero | direct product inspection, Page Flows/SaaSFrame where relevant | popularity/frequency alone |
| How should semantic UI color and light/dark themes behave? | Apple HIG, IBM/Carbon, Adobe Spectrum, Atlassian | WCAG/accessibility checks, target platform | any one design system as universal styling |
| How do strong brands differentiate within a category? | Pentagram, Wolff Olins, Landor case studies | competitor scan, Brand New/BP&O critique | agency narrative as causal evidence |
| Is a color association evidence-based? | Labrecque & Milne; Elliot & Maier | current peer-reviewed research, cultural context | color-psychology blogs or 'blue = trust' charts |
| Is a visual element genuinely distinctive/ownable? | Jenni Romaniuk / Ehrenberg-Bass distinctive assets work | brand recognition research, competitor prevalence | internal preference alone |
| How should data visualization use color? | IBM Design Language/Carbon, accessible data-viz guidance | task-specific user testing | decorative palette selection |
| What identity trends are current across categories? | Brand New, BP&O | real shipped brands, agency case studies | trend = principle |
| What UI pattern should solve a concrete flow? | Mobbin, Refero, SaaSFrame | usability heuristics, product constraints | screenshot imitation |
| What should make a product feel premium? | category-specific identity cases | audience research, material/typographic system | cream + serif + black as a default recipe |
| What should make an AI product feel intelligent? | actual task model + shipped AI products | interaction quality, explainability, system state | purple gradient/orb/space HUD clichés |

## Research sampling rule

For a major visual direction, collect references from at least three independent origin groups:

1. shipped product/UI evidence;
2. system/platform/research evidence;
3. brand/identity/craft evidence.

For category differentiation, include at least one counterexample that breaks the dominant category convention successfully.

- Mobbin — https://mobbin.com/

## Reference hygiene

Always record:
- source;
- date accessed;
- why it is relevant;
- what mechanism is being extracted;
- what limitation applies;
- whether it supports or challenges the proposed direction.

Never make the final design visually converge on a single reference source.
