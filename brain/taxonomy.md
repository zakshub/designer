# Taxonomy v1.0.0

The machine-readable source is [taxonomy.json](taxonomy.json). Shared schemas enumerate the same domains.

Lifecycle: draft → in-review → published. Rejection returns to draft. Content edits clear approval. Expiry/dependency changes mark published work stale. Retirement removes active guidance; supersession identifies a same-type successor.

Confidence below 0.4 is a lead. Values 0.4–0.79 are contextual estimates. Values 0.8–1 and canonical trust require two independent non-weak source groups. These thresholds are policy, not calibrated probabilities of truth.
