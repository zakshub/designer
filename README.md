# DESIGNER Brain

DESIGNER Brain is a source grounded design intelligence repository for Codex, Claude and other agentic design workflows.

It is not a style dump and it is not a collection of copied articles. The repository stores reusable design judgement as explicit skills, evidence backed principles, expert intelligence, standards, patterns, critiques and production rules.

## Brain layers

1. Skills
Reusable execution capabilities such as product design, UX architecture, visual design, typography, accessibility, critique, motion and Figma production.

2. Standards
Authoritative guidance from sources such as W3C WCAG, Apple HIG, Material, Fluent, Atlassian, GOV.UK, Figma and other established systems.

3. Expert intelligence
Structured synthesis of publicly documented work, talks, interviews, books, articles and case studies from leading practitioners across graphic design, UX, UI, digital art, typography, branding, motion, creative direction, interaction and adjacent disciplines.

4. Evidence
Every acquired rule must retain provenance, source URL, retrieval date, domain, evidence type and confidence.

5. Synthesis
Multiple sources are compared before a principle becomes canonical. Conflicting schools of thought remain visible rather than being flattened into one false universal rule.

6. Continuous ingestion
New sources can be researched, normalized, deduplicated, scored, reviewed and promoted into the canonical brain without rewriting the entire repository.

## Core principle

The system should learn how strong designers think, not merely imitate how their work looks.
