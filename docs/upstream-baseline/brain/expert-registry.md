## Expansion rule

The registry is deliberately open ended. New people or studios are added only when there is enough public primary or high quality secondary material to extract meaningful reusable intelligence.

Each profile should capture:

domain
career context
documented principles
decision patterns
signature strengths
common critiques or limitations
representative work
source records
transferable rules
rules that should not be generalized
