# SENTINEL DESIGNER BRAIN

## Purpose

This pack is the implementation handoff for Codex.

The repository is:

https://github.com/zakshub/designer

The system to build is called Sentinel Designer Brain.

Sentinel is not a prompt library, a design reference folder, a Figma automation utility, a static knowledge base, or a generic AI design assistant.

Sentinel is a continuously evolving design intelligence organism.

It learns through research, observation, visual and textual evidence, expert knowledge, standards, experimentation, project outcomes, critique, failure, correction, retention, and forgetting.

Its purpose is not to know everything.

Its purpose is to improve design judgment over time.

## Immediate instruction to Codex

Do not try to build the entire system in one pass.

Start with Phase 0 and Phase 1 only.

Phase 0 establishes identity, constitution, quality rules, evidence rules, originality rules, the definition of indefinite learning, and the relationship with the Studio brain.

Phase 1 establishes repository architecture, schemas, identifiers, metadata, relationships, validation, and basic retrieval structure.

Do not implement autonomous crawling before the knowledge model and evidence rules exist.

Do not fill the repository with unreviewed scraped content.

Do not create UI before the backend mental model is stable enough to expose meaningful state.
