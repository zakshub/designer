# Codex Kickoff Prompt

You are implementing Sentinel Designer Brain inside:

https://github.com/zakshub/designer

Read the entire handoff pack before changing architecture.

Your first objective is not to build the whole system.

Your first objective is to establish Phase 0 and Phase 1 correctly.

## Sentinel definition

Sentinel Designer Brain is a continuously evolving design intelligence organism.

It learns over time through research, observation, visual and textual evidence, expert knowledge, standards, experimentation, feedback, project outcomes, success, failure, correction, retention, and forgetting.

It is not an infinite knowledge system.

It is an indefinite learning system.

It should develop stronger design judgment over time.

## Non negotiable rules

Do not create a generic AI assistant.

Do not create a prompt dump.

Do not create an unstructured Markdown archive.

Do not mass scrape content.

Do not treat Awwwards as a style library.

Do not copy designers.

Do not merge conflicting design philosophies into a false universal rule.

Do not let one weak source become canonical knowledge.

Do not let Designer Brain hallucinate Studio Brain expertise.

Do not let Studio Brain invent product design decisions.

Do not start autonomous crawling before evidence schemas and validation exist.

Do not create final frontend UI before the cognitive model is stable enough to expose meaningful state.

## Definition of success

Codex should be able to answer:

What is Sentinel

What does indefinite mean

How does knowledge enter the brain

How does knowledge become trusted

How are contradictions represented

How is stale knowledge handled

How does the system forget

How do skills use knowledge

How do Designer and Studio cooperate

What prevents generic AI design

How will future learning affect future design decisions

If these questions cannot be answered from the repository itself, Phase 0 and Phase 1 are incomplete.
